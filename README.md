## 🗂️ Функціональні модулі та інструменти

### 1. Основні та наукові розрахунки
* **Базова арифметика**: Додавання, віднімання, множення, ділення, дужки будь-якої вкладеності, відсотки, зміна знаку ($\pm$), обернене значення ($1/x$).
* **Пам'ять калькулятора**: Класичні операції `MC`, `MR`, `M+`, `M-` + **4 незалежні слоти пам'яті (M1..M4)** зі швидким збереженням та викликом.
* **Тригонометрія**: $\sin, \cos, \tan, \cot, \sec, \csc$ у градусах (`DEG`), радіанах (`RAD`) та градах (`GRAD`).
* **Обернені та гіперболічні функції**: $\arcsin, \arccos, \arctan, \operatorname{arcctg}$, а також $\sinh, \cosh, \tanh, \operatorname{coth}, \operatorname{asinh}, \operatorname{acosh}, \operatorname{atanh}$.
* **Логарифми та степені**: $\ln(x), \log_{10}(x), \log_2(x), \log_y(x), e^x, 10^x, 2^x, x^y, x^2, x^3, \sqrt{x}, \sqrt[3]{x}, \sqrt[y]{x}$.
* **Тригонометричне коло**: Інтерактивне візуальне коло з відображенням кута в градусах/радіанах, проєкцій $\sin/\cos$ та значень.
* **База констант**: 20+ фундаментальних математичних ($\pi, e, \varphi, \sqrt{2}, \ln 2$) та фізичних констант ($c, G, h, k_B, N_A, e, m_e, \varepsilon_0$).

---

### 2. Лінійна алгебра, вектори та комплексні числа
* **3D Вектори**:
  * Скалярний добуток ($\vec{u} \cdot \vec{v}$) та векторний добуток ($\vec{u} \times \vec{v}$).
  * Довжини векторів ($|\vec{u}|, |\vec{v}|$), відстань між ними та кут у градусах і радіанах.
* **Матриці 2×2 та 3×3**:
  * Розрахунок детермінанта ($\det A$), сліду ($\operatorname{tr} A$) та рангу.
  * Додавання, віднімання, матричне множення, транспонування ($A^T$) та знаходження оберненої матриці ($A^{-1}$).
* **Комплексні числа $\mathbb{C}$**:
  * Додавання, віднімання, множення та ділення у формі $a + bi$.
  * Знаходження модуля $|z|$, аргументу $\arg(z)$, спряженого числа $\bar{z}$ та тригонометричної/полярної форми $r(\cos\varphi + i\sin\varphi)$.

---

### 3. Геометрія, алгебра та математичний аналіз
* **Квадратні рівняння**: Розв'язання $ax^2 + bx + c = 0$ з розрахунком дискримінанта $D$, дійсних чи комплексних коренів ($x_1, x_2$) та координат вершини параболи.
* **Розв'язувач трикутників**:
  * Розрахунок за трьома сторонами (**SSS**), двома сторонами та кутом (**SAS**), двома кутами та стороною (**ASA**).
  * Обчислення всіх сторін, кутів, периметра, площі за формулою Герона, радіусів вписаного ($r$) та описаного ($R$) кіл.
* **Теорія чисел (Prime, GCD, LCM)**:
  * Перевірка числа на простоту (Primality Test).
  * Розклад на прості множники (факторизація).
  * Найбільший спільний дільник (НСД / GCD) та найменше спільне кратне (НСК / LCM) за алгоритмом Евкліда.
* **Дослідження функцій $f(x)$**: Обчислення значень та побудова таблиці функції на проміжку $[a, b]$ із заданим кроком $h$.
* **2D Графік на Canvas**: Побудова графіків елементарних функцій ($\sin, \cos, \tan, x^2, x^3, \sqrt{x}, \ln x, 1/x, e^x$) на інтерактивній координатній сітці.
* **Фізичні формули**: Інтерактивний каталог формул з кінематики, динаміки, термодинаміки, електрики та оптики з автоматичним знаходженням невідомих величин.
* **Математичний довідник**: Довідкова шпаргалка з тригонометрії, алгебри, похідних, границь та геометрії.

---

### 4. Програмістський режим та бітові маски
* **Системи числення**: Миттєва взаємна конвертація між **HEX** (16), **DEC** (10), **OCT** (8) та **BIN** (2).
* **Побітові операції**: `AND`, `OR`, `XOR`, `NOT`, побітові зсуви вліво (`<<`) та вправо (`>>`).
* **Візуалізатор бітових масок**: Інтерактивна 16-бітна панель із клікабельними бітами (0/1) у реальному часі.

---

### 5. Фінанси, конвертація та щоденні задачі
* **Кредитний та іпотечний калькулятор**: Розрахунок ануїтетних та диференційованих платежів, щомісячного внеску, переплати та загальної вартості кредиту.
* **Фінансовий аналізатор**: Складні відсотки з капіталізацією та розрахунок майбутньої вартості інвестицій ($FV$).
* **Калькулятор вигідної покупки (Best Deal)**: Порівняння ціни за кілограм, літр або штуку для двох товарів різної маси/ціни.
* **Відсотки та націнки**: Розрахунок $X\%$ від $Y$, додавання/віднімання відсотків, відсоткова різниця.
* **Конвертер величин**: 10 категорій (Довжина, Маса, Площа, Об'єм, Температура, Швидкість, Тиск, Енергія, Потужність, Цифрові дані).
* **Конвертер валют**: Розрахунок курсів UAH, USD, EUR, GBP, PLN, JPY, CHF тощо.
* **Калькулятор дат**: Різниця між двома датами (дні, тижні, місяці, роки), додавання/віднімання днів, день тижня та високосний рік.
* **Генератор випадкових чисел (RNG)**: Генератор діапазонів, кидок грального кубика (d4, d6, d8, d10, d12, d20, d100) та підкидання монети.
* **Статистичний аналіз**: Розрахунок середнього, медіани, моди, дисперсії ($\sigma^2$), стандартного відхилення ($\sigma$), суми, мінімуму та максимуму для довільного масиву даних.

---

### 6. Історія, аудиторська стрічка та експорт
* **Журнал історії**: Автоматичне збереження всіх обчислень у `localStorage`, пошук по виразах, повторне завантаження результату на дисплей.
* **Експорт історії**: Вивантаження журналу обчислень у форматах `.txt`, `.csv` або `.json`.
* **Аудиторська розрахункова стрічка (Paper Tape)**: Бухгалтерський лог послідовних операцій із функцією друку (`Print`).
* **Закладки (Bookmarks)**: Збереження обраних констант, формул та виразів із тегами.

## 🚀 Швидкий запуск та встановлення

### Передумови
Встановлений [Node.js](https://nodejs.org/) (версія 14 або вище). Жодних сторонніх npm-пакетів не потрібно — проект використовує виключно чисті стандартні веб-технології!

### Запуск локального сервера
1. Відкрийте термінал у папці проекту:
   ```bash
   npm start
   ```
   *або запустіть безпосередньо:*
   ```bash
   node server.js
   ```
   *або двічі клікніть по файлу:* `start.bat`

2. Калькулятор автоматично відкриється у вашому браузері за адресою:
   👉 **`http://localhost:3000`**

## 🛠️ Збирання проекту (Build System)

Якщо ви редагуєте окремі модулі в папках `css/`, `js/` або `views/`, виконайте команду збирання для оновлення кореневих файлів `index.html`, `style.css` та `app.js`:

```bash
npm run build
```
*або:*
```bash
node build.js
```

Скрипт [build.js](file:///d:/calculator/build.js):
1. Очищує приховані UTF-8 BOM маркери.
2. Об'єднує 16 CSS-модулів у структурований [style.css](file:///d:/calculator/style.css).
3. Об'єднує 46 JS-модулів у правильному порядку залежностей у [app.js](file:///d:/calculator/app.js).
4. Об'єднує 9 partials та 41 modal у цілісний [index.html](file:///d:/calculator/index.html).
